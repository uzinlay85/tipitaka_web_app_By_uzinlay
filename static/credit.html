တိပိဋက ပါဠိတော် နှင့် မြန်မာပြန် Web Application

ကျေးဇူးတင်လွှာ၊ ရည်ရွယ်ချက် နှင့် မူရင်းဖန်တီးသူအား အလေးထားခွင့်တောင်းစာ

🙏 မူရင်း ဆော့ဝဲလ်ဖန်တီးသူအား အသိအမှတ်ပြုခြင်း

ဤ Web Application တွင် အသုံးပြုထားသော အခြေခံကျမ်းစာဒေတာများ၊ မာတိကာများနှင့် ပါဠိ-မြန်မာ အဘိဓာန်ဒေတာများသည် မူရင်း Android ဆော့ဝဲလ်များမှ ဖြစ်ပါသည် -

☸️ မူရင်း Android App များ:

  • Tipitaka Pali (တိပိဋကပါဠိ) - ပါဠိတော်၊ အဋ္ဌကထာ၊ ဋီကာ စုစုပေါင်း ၁၉၂ အုပ်
  • Tipitaka Myanmar (တိပိဋက မြန်မာပြန်) - သာသနာရေးဦးစီးဌာန မြန်မာပြန် စာအုပ် ၆၀

✍️ မူရင်း ရေးသားဖန်တီးသူ: Pn Daza (သာသနာပြု အရှင်မြတ်)

📧 Email: mrpndaza@gmail.com | 🌐 Facebook: Pn Daza Facebook Profile

💡 ဤ Web App ကို ဖန်တီးတည်ဆောက်ရခြင်း ရည်ရွယ်ချက်

  • ကွန်ပျူတာနှင့် ဖုန်းများပေါ်တွင် Install လုပ်စရာမလိုဘဲ လွယ်ကူစွာ ဖတ်ရှုနိုင်စေရန်: မူရင်းဆော့ဝဲလ်များအနေဖြင့် Android အပြင် Windows, macOS အတွက်ပါ ရှိသော်လည်း အချို့သော သုံးစွဲသူများအတွက် Install ပြုလုပ်ရာတွင် အဆင်မပြေမှုများ ရှိနိုင်ခြင်း၊ Storage မလောက်သော ဖုန်းများနှင့် ကွန်ပျူတာများတွင်ပါ မမ်မိုရီနေရာမယူဘဲ မည်သည့် Browser မှမဆို အလွယ်တကူ တိုက်ရိုက် လျင်မြန်စွာ ဖွင့်လှစ်ဖတ်ရှုနိုင်စေရန် ရည်ရွယ်ပါသည်။
  • မိမိကိုယ်တိုင် လိုအပ်ချက်များကို ဖြည့်စွက်ပြင်ဆင် အသုံးပြုနိုင်ရန်:
    • ဆဋ္ဌမူ မူရင်းစာအုပ်အတိုင်း ဂါထာသတ်ပုံ: ကော်မာများအစား မူရင်းဆဋ္ဌမူစာအုပ်အတိုင်း ပထမ/တတိယပုဒ်တွင် ပုဒ်ထီး ( ၊ )၊ ဒုတိယ/စတုတ္ထပုဒ်တွင် ပုဒ်မ ( ။ ) သတ်ပုံများဖြင့် စနစ်တကျ ပြင်ဆင်ဖတ်ရှုနိုင်ခြင်း။
    • ဆဋ္ဌမူ ပေယျာလ အထားအသို: အကျဉ်းချုံးနေရာများတွင် မူရင်းအတိုင်း ။ ပ ။ ဖြင့် တိကျစွာ ပြသပေးခြင်း။
    • ပါဠိ နှင့် မြန်မာပြန် ယှဉ်တွဲဖတ်ရှုမှု (Dual View): ပါဠိတော်နှင့် မြန်မာပြန်ကို ဘေးချင်းယှဉ်တွဲ တိုက်ဆိုင်ဖတ်ရှုနိုင်ခြင်း နှင့် ခလုတ်တစ်ချက်ဖြင့် အပြန်အလှန် ခုန်ကူးဖတ်ရှုနိုင်ခြင်း။
    • စာမျက်နှာ ဆက်တိုက်ဖတ်ရှုမှု (Continuous Stream Feed): Facebook ကဲ့သို့ စာမျက်နှာများကို စဉ်ဆက်မပြတ် ဆက်တိုက်ဖတ်ရှုနိုင်ခြင်း။
    • ပါဠိ ဝိဘတ်ဖြုတ် အနက်ရှာဖွေမှု: စာလုံးတစ်လုံးချင်းစီကို ကလစ်နှိပ်ရုံဖြင့် အဘိဓာန် ၈ မျိုးမှ အနက်ထွက်ပေါ်ခြင်း။

📜 မူရင်း ရေးသားသူ အရှင်မြတ် (Pn Daza) အား လေးစားကြည်ညိုစွာ မှတ်တမ်းတင်ခြင်းနှင့် ခွင့်တောင်းစာ

ဤအရှင်မြတ် (Pn Daza) သည် အခု အသုံးပြုထားသော App နှစ်ခုအပြင် တခြား ဘုရားဟော ပိဋကတ်ကျမ်းစာဆိုင်ရာ သာသနာအတွက် အလွန်အကျိုးများသော Applications များစွာကို ရေးသားပြုစုထားသူ ဖြစ်ပါသည်။

ပိဋကတ်ကျမ်းစာ လေ့လာသူတိုင်း အားကိုးအားထား ပြုရသည့် Apps များစွာကို တည်ဆောက်၍ သာသနာတော်ကို အကျိုးပြုခဲ့သော မူရင်း App ရေးသားသူ Pn Daza ၏ တည်ဆောက်ခဲ့သော ကြိုးစားအားထုတ်မှုနှင့် ဉာဏ်ပညာအား လေးစားကြည်ညိုစွာဖြင့် မှတ်တမ်းတင် ဂုဏ်ပြုအပ်ပါသည်။

အခုလို (မိမိလိုအပ်ချက်အတွက်) ပြင်ဆင် အသုံးပြုတာကိုလည်း ခွင့်ပြုပေးဖို့အတွက် မူရင်းဖန်တီးသူ အရှင်မြတ်အား လေးစားစွာဖြင့် ခွင့်ပြုပေးပါရန် တောင်းပန်အပ်ပါသည်။

🤖 နည်းပညာ တည်ဆောက်မှု နှင့် AI အကူအညီ

ဤ Web Application ကို ပြင်ဆင်အသုံးပြုသူ Ashin Pannasetthalankara သည် Web Development နည်းပညာကို အခြေခံမျှသာ တတ်ကျွမ်းသူ ဖြစ်သည့်အတွက်၊ ဤစနစ်တစ်ခုလုံး၏ Backend (Python Flask API)၊ Frontend (Modern Responsive Web Interface)၊ ဆဋ္ဌမူ ဂါထာသတ်ပုံနှင့် ပေယျာလ အလိုအလျောက် သန့်စင်စနစ်၊ စာမျက်နှာ အကူးအပြောင်းနှင့် Instant Search နည်းပညာများအားလုံးကို Antigravity AI (Google DeepMind) ၏ နည်းပညာအကူအညီဖြင့် အဆင့်ဆင့် တိုင်ပင်ဆွေးနွေးကာ ရေးသားတည်ဆောက်ခဲ့ခြင်း ဖြစ်ပါသည်။ နည်းပညာ အခက်အခဲများကို လွယ်ကူလျင်မြန်စွာ ကျော်လွှားနိုင်စေခဲ့သော AI စနစ်အားလည်း မှတ်တမ်းတင် ဂုဏ်ပြုအပ်ပါသည်။
