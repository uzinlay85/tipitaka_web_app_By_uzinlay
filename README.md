# တိပိဋက ပါဠိတော် နှင့် မြန်မာပြန် (Tipitaka Pali & Myanmar Web Reader)

ဤ Application သည် ဆဋ္ဌသင်္ဂါယနာ **တိပိဋက ပါဠိတော် (၁၉၂ အုပ်)** နှင့် **တိပိဋက မြန်မာပြန် (၆၀ အုပ်)**၊ အဋ္ဌကထာ၊ ဋီကာ ကျမ်းစာများနှင့် ပါဠိ-မြန်မာ အဘိဓာန် ဒေတာများကို ပေါင်းစပ်၍ **Browser ပေါ်တွင် အလွန်မြန်ဆန် ချောမွေ့စွာ ဖတ်ရှုလေ့လာနိုင်ရန်** Python (Flask) + Modern Web UI ဖြင့် ဖန်တီးထားသော Self-hosted Web Application ဖြစ်ပါသည်။

---

## 🌟 အဓိက ပါဝင်သော လုပ်ဆောင်ချက်များ (Key Features)

### ၁။ ပါဠိတော် (၁၉၂ အုပ်) နှင့် မြန်မာပြန် (၆၀ အုပ်) အပြည့်အစုံ
- **ပါဠိတော် ကျမ်းစာများ:** မူလ၊ အဋ္ဌကထာ၊ ဋီကာ စုစုပေါင်း ၁၉၂ အုပ် (စာမျက်နှာ ၅၉,၀၀၈ မျက်နှာ)
- **မြန်မာပြန် ကျမ်းစာများ:** ဝိနည်း၊ ဒီဃနိကာယ်၊ မဇ္ဈိမနိကာယ်၊ သံယုတ္တနိကာယ်၊ အင်္ဂုတ္တရနိကာယ်၊ ခုဒ္ဒကနိကာယ်၊ အဘိဓမ္မာ၊ ဇာတ်တော်ကြီး ၅၅၀၊ ဓမ္မပဒအဋ္ဌကထာ၊ ဝိသုဒ္ဓိမဂ် မြန်မာပြန် စုစုပေါင်း ၆၀ အုပ် (စာမျက်နှာ ၂၃,၃၉၀ မျက်နှာ)

### ၂။ ဖတ်ရှုမှု ပုံစံ ၃ မျိုး (Reading Modes)
1. **☸️ ပါဠိတော် Mode:** ပါဠိတော်မူရင်းစာသားများကို သီးသန့်ဖတ်ရှုနိုင်ခြင်း။
2. **🇲🇲 မြန်မာပြန် Mode:** တိပိဋက မြန်မာပြန်ကျမ်းစာများကို သီးသန့်ဖတ်ရှုနိုင်ခြင်း။
3. **📖 ယှဉ်တွဲဖတ်ရှုခြင်း (Dual Split View):** ဘယ်ဘက်ခြမ်းတွင် ပါဠိတော်နှင့် ညာဘက်ခြမ်းတွင် မြန်မာပြန်တို့ကို စာပိုဒ်/အခန်းအလိုက် ဘေးချင်းယှဉ်တွဲ၍ တစ်ပြိုင်နက် ဖတ်ရှုနိုင်ခြင်း။

### ၃။ ပါဠိ နှင့် မြန်မာပြန် အပြန်အလှန် အမြန်ကူးပြောင်းနိုင်ခြင်း (Cross-Linking)
- ပါဠိတော် ဖတ်ရှုနေစဉ် အပေါ်ဘားရှိ **"🇲🇲 မြန်မာပြန်သို့"** ခလုတ်ကို နှိပ်လိုက်ရုံဖြင့် အဆိုပါစာပိုဒ်နှင့် ကိုက်ညီသော မြန်မာပြန်စာမျက်နှာသို့ တိုက်ရိုက်ရောက်ရှိသွားခြင်း။
- မြန်မာပြန် ဖတ်ရှုနေစဉ် အပေါ်ဘားရှိ **"☸️ ပါဠိတော်သို့"** ခလုတ်ကို နှိပ်လိုက်ရုံဖြင့် မူရင်းပါဠိတော် စာမျက်နှာသို့ တိုက်ရိုက် ပြန်လည်ရောက်ရှိခြင်း။

### ၄။ ပါဠိ-မြန်မာ အဘိဓာန် အပြန်အလှန် ရှာဖွေမှု (Instant Click-to-Lookup)
- စာဖတ်နေစဉ် မသိသော ပါဠိစာလုံး တစ်လုံးချင်းစီကို **Click နှိပ်လိုက်ရုံဖြင့်** အဘိဓာန် ၈ မျိုးလုံးမှ အဓိပ္ပာယ် ချက်ချင်း ထွက်ပေါ်လာခြင်း။
- ပါဠိ ဝိဘတ်ဖြုတ်နည်း (Pali Stemming) ပါဝင်သဖြင့် `ဗုဒ္ဓေါ`၊ `ဓမ္မဿ`၊ `သမ္မာသမ္ဗုဒ္ဓဿ` စသည်တို့ကိုလည်း မူရင်းပုဒ်၏ အနက်ကို ရှာဖွေပေးခြင်း။

### ၅။ အလွန်လျင်မြန်သော Full-Text Word & Sutta Search (ရှာဖွေမှုစနစ်)
- ပါဠိစာလုံးပေါင်း **၉၂၃,၆၉၅ လုံး**၊ သုတ္တန်ပေါင်း **၆,၈၈၁ ပုဒ်**၊ မြန်မာပြန် မာတိကာပေါင်း **၁၃,၈၄၈ ခု** အတွင်း မီလီစက္ကန့်ပိုင်းအတွင်း ရှာဖွေနိုင်ခြင်း။

### ၆။ မျက်စိအေးစေသော Themes ၃ မျိုး နှင့် Font Size ချိန်ညှိမှု
- 📜 စက္ကူရောင် (Paper Mode - Warm Parchment)
- ☀️ နေ့ရောင် (Day Mode)
- 🌙 ညရောင် (Dark Mode)

## ✨ ထပ်မံဖြည့်စွက် ပြုပြင်ပြီးစီးမှုများ (Recent Updates & Enhancements)

### ၁။ ဆဋ္ဌမူစာအုပ် မူရင်းအတိုင်း ဂါထာပါဠိတော်များ သတ်ပုံသန့်စင်ခြင်း (Authentic Chatthasangayana Gāthā Typography)
- ဂါထာပါဠိတော်များအားလုံးတွင် အင်္ဂလိပ်ကော်မာများအစား ဆဋ္ဌမူစာအုပ် မူရင်းအတိုင်း **ပထမပုဒ်နှင့် တတိယပုဒ်အဆုံးတွင် ပုဒ်ထီး ( ၊ )**၊ **ဒုတိယပုဒ်နှင့် စတုတ္ထပုဒ်အဆုံးတွင် ပုဒ်မ ( ။ )** အဖြစ် Server (Python API) နှင့် Frontend (Web UI) နှစ်ဘက်စလုံးမှ အလိုအလျောက် တိကျစွာ ပြောင်းလဲပေးခြင်း။
  ```
  (နမူနာ - ဓမ္မပဒ အပ္ပမာဒဝဂ် ဂါထာ ၂၁)
  ၂၁။ အပ္ပမာဒေါ အမတပဒံ၊ ပမာဒေါ မစ္စုနော ပဒံ။
      အပ္ပမတ္တာ န မီယန္တိ၊ ယေ ပမတ္တာ ယထာ မတာ။
  ```
- စကားပြေ (Bodytext / Prose) များတွင် မလိုအပ်သော English comma များကို သန့်စင်ဖယ်ရှားပေးခြင်း။

### ၂။ ဆဋ္ဌမူ ပေယျာလ အကျဉ်းချုံး သင်္ကေတများ (Authentic Peyāla Formatting)
- အရင်စာပိုဒ်နှင့်တူသော အကျဉ်းချုံးနေရာများ (`...ပ...` သို့မဟုတ် `…ပေ…`) ကို ဆဋ္ဌမူစာအုပ် မူရင်းအတိုင်း **`။ ပ ။`** အဖြစ် ပါဠိတော်နှင့် မြန်မာပြန် နှစ်မျိုးလုံးတွင် စနစ်တကျ ပြောင်းလဲပြသပေးခြင်း။
  ```
  (နမူနာ - ဝိမာနဝတ္ထု ဂါထာ ၂၄၉)
  ၂၄၉။ သာ ဒေဝတာ အတ္တမနာ။ ပ ။ ယထာ ကမ္မဿိဒံ ဖလံ။
  ```

### ၃။ စဉ်ဆက်မပြတ် ဆက်တိုက်ဖတ်ရှုနိုင်ခြင်း (Continuous Stream Feed / Facebook-Style Scroll)
- **Desktop တွင်:** Mouse Wheel ကို အောက်သို့ ဆက်တိုက်လှိမ့်သွားရုံဖြင့် စာမျက်နှာ (၁)၊ (၂)၊ (၃) စသည်ဖြင့် စဉ်ဆက်မပြတ် ဆက်တိုက်ထွက်ပေါ်လာခြင်း။
- **Mobile တွင်:** လက်ချောင်းဖြင့် အပေါ်သို့ ပုံမှန်အတိုင်း အပေါ်သို့ ဆွဲတင်ဖတ်ရှုနိုင်ခြင်း။
- စာဖတ်သူ၏ စိတ်ကြိုက်အလိုက် **"စာမျက်နှာ ဆက်တိုက်" (Feed Mode)** သို့မဟုတ် **"စာမျက်နှာ တစ်မျက်နှာချင်း" (Single Page Mode)** ကို ခလုတ်တစ်ချက်နှိပ်ရုံဖြင့် လွတ်လပ်စွာ ပြောင်းလဲဖတ်ရှုနိုင်ခြင်း။

### ၄။ ကျမ်းပေါင်းချုပ် စာအုပ်များ၏ မူရင်း စာမျက်နှာနယ်နိမိတ်များ အပြည့်အဝ ထိန်းသိမ်းခြင်း (Multi-Treatise Volume Page Boundaries)
- စာအုပ်တစ်အုပ်တည်းတွင် ကျမ်းစာပေါင်းများစွာ ပေါင်းစည်းထားသော ကျမ်းများ (ဥပမာ- ခုဒ္ဒကနိကာယ် ကျမ်းများ၊ အဘိဓမ္မာ ညဝါကျမ်းများ) တွင် စာမျက်နှာ ၁ မှ မဟုတ်ဘဲ မူရင်းစာအုပ် စာမျက်နှာအလိုက် (ဥပမာ- ထေရီဂါထာ စာမျက်နှာ ၃၇၇ မှ စတင်ခြင်း) မူရင်းအတိုင်း တိကျစွာ ဖွင့်လှစ်နိုင်ခြင်း။

### ၅။ မူရင်း Android APK အတိုင်း လှပသော ပင်မမာတိကာကြီးနှင့် Mobile Navigation Bar
- **ပင်မစာမျက်နှာ (Home):** မူရင်း Android APK ကဲ့သို့ သပ်ရပ်သော နိကာယ်/ကဏ္ဍအလိုက် မာတိကာကတ်ပြားကြီးများ။
- **Mobile Bottom Nav:** ဖုန်းစခရင်များတွင် အသုံးပြုရ အလွန်လွယ်ကူသော Floating Bottom Navigation Bar (စာအုပ်စင်၊ မာတိကာ၊ ရှာဖွေမှု၊ အဘိဓာန်၊ အခြား)။
- **အစဆုံးဝင်ရောက်ချိန် ပင်မမာတိကာ ပွင့်လှစ်ခြင်း:** App သို့ စတင်ဝင်ရောက်ချိန်တွင် စာဖတ်မျက်နှာပြင် မရှုပ်ထွေးစေဘဲ အမြဲတမ်း သန့်ရှင်းသော ပင်မကျမ်းစာမာတိကာကတ်ပြားကြီးများဖြင့် အစပြုနိုင်ရန် စီမံထားခြင်း။

### ၆။ စာကြောင်းအကူးအပြောင်းတွင် စာလုံးဆင့်များ ပြတ်တောက်၍ (+) ဝိရာမသင်္ကေတ မဖြစ်ပေါ်စေရန် အမြစ်ပြတ် ဖြေရှင်းခြင်း (Line-Break Virama Conjunct Fix)
- **ပြဿနာ:** မြန်မာစာ/ပါဠိတော် ယူနီကုဒ်တွင် စာလုံးဆင့် (ဥပမာ `ဘဂဝန္တာနံ`, `သာရိပုတ္တော`, `ဗြဟ္မစရိယံ`, `စိရဋ္ဌိတိကံ`) များကို Browser (Chromium / WebKit) များက စာကြောင်းအဆုံးသို့ ရောက်သောအခါ စာလုံးဆင့်အလယ် (`\u1039` virama အဆုံး) မှ ဖြတ်ချလိုက်ခြင်းကြောင့် အပေါ်စာကြောင်းအဆုံး၌ ဝိရာမ Fallback သင်္ကေတ အပေါင်းလက္ခဏာ **`+` (`₊`)** ဖြစ်ပေါ်နေခဲ့ခြင်း။ (မူရင်းဆော့ဝဲလ်၏ `help.html` လမ်းညွှန်တွင်ပါ Android WebView ၏ အားနည်းချက်အဖြစ် မှတ်တမ်းတင်ထားခဲ့ရသော ပြဿနာဖြစ်ပါသည်)။
- **ဖြေရှင်းချက်:** ပါဠိတော်နှင့် မြန်မာပြန်ရှိ စာလုံးများနှင့် စာလုံးဆင့်များအားလုံးကို `white-space: nowrap` ပါရှိသော စနစ်ဖြင့် လုံခြုံစွာ ထိန်းကျောင်းပေးလိုက်သောကြောင့် စာကြောင်းခေါက်ရာတွင် မည်သည့်အခါမှ စာလုံးဆင့်ကြားမှ ဖြတ်မချတော့ဘဲ စာလုံးတစ်လုံးလုံး ညီညီညာညာ အောက်ကြောင်းသို့ ဆင်းသွားသဖြင့် `+` လုံးဝမဖြစ်ပေါ်တော့ပါ။

### ၇။ ယှဉ်တွဲဖတ်ရှုမှု စနစ် (Dual Split View) ၏ အဆင့်မြင့် စာမျက်နှာ/စာပိုဒ် ချိန်ညှိမှု စနစ်များ (Advanced Split-View Controls)
- **သီးခြား စာမျက်နှာလှန်ခလုတ်များ (Independent Left/Right Controls):** ပါဠိတော်ဘက်ခြမ်းနှင့် မြန်မာပြန်ဘက်ခြမ်းတို့တွင် သီးခြား စာမျက်နှာရှေ့တိုး/နောက်ဆုတ်ခလုတ်များ (`◀ စာ [X] / [Y] ▶`) နှင့် စာမျက်နှာရိုက်ထည့်ခလုတ်များ ပါဝင်သဖြင့် ပါဠိတော်နှင့် မြန်မာပြန် စာမျက်နှာမညီသည့်အခါ လွတ်လပ်စွာ ချိန်ညှိဖတ်ရှုနိုင်ခြင်း။
- **အပြန်အလှန် စာပိုဒ်ကလစ်နှိပ် ခုန်ကူးခြင်း (Interactive Paragraph Sync & Pulse Highlight):** ပါဠိတော်ဘက်မှ စာပိုဒ်နံပါတ် (ဥပမာ `၁၇။`) ကို ကလစ်နှိပ်ပါက မြန်မာပြန်ဘက်ရှိ ထိုစာပိုဒ်ဆီသို့ အလိုအလျောက် scroll ဆွဲပေးပြီး highlight လင်းလက်ပြသပေးခြင်း (မြန်မာပြန်မှ အပိုဒ်နံပါတ်ကို နှိပ်ပါကလည်း ပါဠိတော်ဆီသို့ ခုန်ကူးပြသခြင်း)။
- **တစ်ပြိုင်တည်း ညှိယူပေးသော ခလုတ် (Sync Matching Pages Button):** စာမျက်နှာများ လွတ်လပ်စွာ လှန်ထားသော်လည်း မူလကိုက်ညီသော စာမျက်နှာသို့ တစ်ချက်နှိပ်ရုံဖြင့် အချိန်မရွေး ပြန်လည်ညီညာစေခြင်း။
- **Majority Paragraph Voting Algorithm:** စာမျက်နှာတစ်ခုတွင် စာပိုဒ်များစွာ ပါဝင်နေပါက အများဆုံးပါဝင်သော စာမျက်နှာကို Server က အလိုအလျောက် တိကျစွာ ရွေးချယ်ချိတ်ဆက်ပေးခြင်း။

### ၈။ ဂါထာစာကြောင်း အစ/အဆုံး ညီညီညာညာ ညှိယူပေးခြင်း (Gāthā Line Alignment)
- ဂါထာစာပိုဒ်များ၏ စာကြောင်းအစရှိ မညီမညာဖြစ်နေသော space များကို အလိုအလျောက် ရှင်းလင်းပေးပြီး၊ ပထမ/တတိယ/ဒုတိယ/စတုတ္ထပုဒ်များ စာကြောင်းအစအဆုံး တညီတညာတည်း သပ်ရပ်စွာ ပေါ်လွင်စေခြင်း။

### ၉။ ကလစ်တစ်ချက်နှိပ် အဘိဓာန်ရှာဖွေမှု (Word Click Lookup) ပိုမိုတိကျမြန်ဆန်ခြင်း
- ပါဠိစာလုံးများကို သီးခြား token အဖြစ် စနစ်တကျ wrap လုပ်ထားသဖြင့် စာဖတ်နေစဉ် မည်သည့် ပါဠိစာလုံးပေါ်မဆို ကလစ်နှိပ်လိုက်သည်နှင့် ချက်ချင်းတိကျစွာ ဖမ်းယူ၍ အဘိဓာန် ဖွင့်လှစ်ပေးနိုင်ခြင်း။

## 🔄 VPS Server ပေါ်တွင် Update ပြုလုပ်နည်း (GitHub Workflow)

GitHub ပေါ်တွင် Code အသစ်များ ပြင်ဆင်ပြီးသည့်အခါတိုင်း VPS Terminal (SSH) သို့ ဝင်ရောက်ပြီး အောက်ပါ command များကို Run ပေးရုံဖြင့် ၂ စက္ကန့်အတွင်း Update ပြီးစီးပါသည် -

### ဤ Web Application ကို ပြုစုဖန်တီးရခြင်း ရည်ရွယ်ချက် (Purpose of Web Application)
1. **ကွန်ပျူတာနှင့် ဖုန်းများပေါ်တွင် Install လုပ်စရာမလိုဘဲ လွယ်ကူစွာ ဖတ်ရှုနိုင်စေရန်:**
   မူရင်းဆော့ဝဲလ်များအနေဖြင့် Android အပြင် Windows, macOS အတွက်ပါ ရှိသော်လည်း အချို့သော သုံးစွဲသူများအတွက် Install ပြုလုပ်ရာတွင် အဆင်မပြေမှုများ ရှိနိုင်ခြင်း၊ Storage (မမ်မိုရီနေရာလွတ်) မလောက်သော ဖုန်းများနှင့် ကွန်ပျူတာများတွင်ပါ နေရာမယူဘဲ မည်သည့် Browser မှမဆို အလွယ်တကူ တိုက်ရိုက် လျင်မြန်စွာ ဖွင့်လှစ်ဖတ်ရှုနိုင်စေရန် ရည်ရွယ်ပါသည်။
2. **မိမိကိုယ်တိုင် လိုအပ်ချက်များကို ဖြည့်စွက်ပြင်ဆင် အသုံးပြုနိုင်ရန်:**

   - အကျဉ်းချုံးနေရာများတွင် ဆဋ္ဌမူအတိုင်း **`။ ပ ။`** ပေယျာလ အထားအသိုများ ပြင်ဆင်ခြင်း။

   - Facebook ကဲ့သို့ စာမျက်နှာများကို စဉ်ဆက်မပြတ် ဆက်တိုက်ဖတ်ရှုနိုင်သော Stream Feed စနစ်။
   - ကလစ်တစ်ချက်နှိပ်ရုံဖြင့် ပါဠိ ဝိဘတ်ဖြုတ် အနက်ထွက်ပေါ်သော Instant Lookup စနစ်။

   - အခုလို (မိမိလိုအပ်ချက်အတွက်) ပြင်ဆင် အသုံးပြုတာကိုလည်း ခွင့်ပြုပေးဖို့အတွက် မူရင်းဖန်တီးသူ အရှင်မြတ်အား လေးစားစွာဖြင့် ခွင့်ပြုပေးပါရန် တောင်းပန်အပ်ပါသည်။

## 🤖 နည်းပညာ တည်ဆောက်မှု နှင့် AI အကူအညီ (Development & AI Collaboration)

ဤ Web Application ကို ပြင်ဆင်အသုံးပြုသူ **Ashin Pannasetthalankara** သည် Web Development နည်းပညာကို အခြေခံမျှသာ သိရှိနားလည်သူ ဖြစ်သည့်အတွက်၊ ဤစနစ်ကြီးတစ်ခုလုံး၏ -
- **Backend Architecture:** Python (Flask), SQLite Database optimizations, Multi-book indexing, Cache-Control and API endpoints
- **Frontend Modern Web UI:** Responsive Drawer Navigation, Split-screen Dual Reader, Dynamic Continuous Stream Feed (Auto-scroll pagination)
- **Authentic Typography Engine:** ဆဋ္ဌမူ မူရင်းစာအုပ်ကြီးအတိုင်း ဂါထာပါဠိတော်များ၏ ပုဒ်ထီး ( ၊ )၊ ပုဒ်မ ( ။ ) နှင့် ပေယျာလ (`။ ပ ။`) အလိုအလျောက် သန့်စင်စနစ်
- **Instant Search & Stemming Dictionary:** မီလီစက္ကန့်ပိုင်းအတွင်း ရှာဖွေနိုင်သော Universal Search နှင့် ပါဠိ ဝိဘတ်ဖြုတ်နည်းစနစ်

အစရှိသော အဆင့်မြင့် နည်းပညာပိုင်းဆိုင်ရာများနှင့် ပြဿနာဖြေရှင်းမှုများကို **Google DeepMind ၏ Antigravity AI** အကူအညီဖြင့် အသေးစိတ် အဆင့်ဆင့် တိုင်ပင်ဆွေးနွေးကာ ရေးသားတည်ဆောက်ခဲ့ခြင်း ဖြစ်ပါသည်။ နည်းပညာ အခက်အခဲများကို လွယ်ကူလျင်မြန်စွာ ကျော်လွှားနိုင်စေခဲ့သော AI နည်းပညာအားလည်း အထူးပင် မှတ်တမ်းတင် ဂုဏ်ပြုအပ်ပါသည်။
