# တိပိဋက ပါဠိတော် နှင့် မြန်မာပြန် (Tipitaka Pali & Myanmar Web Reader)

ဤ Application သည် ဆဋ္ဌသင်္ဂါယနာ **တိပိဋက ပါဠိတော် (၁၉၂ အုပ်)** နှင့် **တိပိဋက မြန်မာပြန် (၆၀ အုပ်)**၊ အဋ္ဌကထာ၊ ဋီကာ ကျမ်းစာများနှင့် ပါဠိ-မြန်မာ အဘိဓာန် ဒေတာများကို ပေါင်းစပ်၍ **Browser ပေါ်တွင် အလွန်မြန်ဆန် ချောမွေ့စွာ ဖတ်ရှုလေ့လာနိုင်ရန်** Python (Flask) + Modern Web UI ဖြင့် ဖန်တီးထားသော Self-hosted Web Application ဖြစ်ပါသည်။

---

## 🌟 အဓိက ပါဝင်သော လုပ်ဆောင်ချက်များ (Key Features)

### ၁။ ပါဠိတော် (၁၉၂ အုပ်) နှင့် မြန်မာပြန် (၆၀ အုပ်) အပြည့်အစုံ
- **ပါဠိတော် ကျမ်းစာများ:** မူလ၊ အဋ္ဌကထာ၊ ဋီကာ စုစုပေါင်း ၁၉၂ အုပ် (စာမျက်နှာ ၅၉,၀၀၈ မျက်နှာ)
- **မြန်မာပြန် ကျမ်းစာများ:** ဝိနည်း၊ ဒီဃနိကာယ်၊ မဇ္ဈိမနိကာယ်၊ သံယုတ္တနိကာယ်၊ အင်္ဂုတ္တရနိကာယ်၊ ခုဒ္ဒကနိကာယ်၊ အဘိဓမ္မာ၊ ဇာတ်တော်ကြီး ၅၅၀၊ ဓမ္မပဒအဋ္ဌကထာ၊ ဝိသုဒ္ဓိမဂ် မြန်မာပြန် စုစုပေါင်း ၆၀ အုပ် (စာမျက်နှာ ၂၃,၃၉၀ မျက်နှာ)

### ၂။ ဖတ်ရှုမှု ပုံစံ ၃ မျိုး (Reading Modes)
1. **☸️ ပါဠိတော် Mode:** ပါဠိတော်မူရင်းစာသားများကို သီးသန့်ဖတ်ရှုနိုင်ခြင်း။
2. **🇲🇲 မြန်မာပြန် Mode:** တိပိဋက မြန်မာပြန်ကျမ်းစာများကို သီးသန့်ဖတ်ရှုနိုင်ခြင်း။
3. **📖 ယှဉ်တွဲဖတ်ရှုခြင်း (Dual Split View with Dynamic Companion Tabs):** ဘယ်ဘက်ခြမ်းတွင် မူလကျမ်းစာနှင့် ညာဘက်ခြမ်းတွင် အဋ္ဌကထာ၊ ဋီကာ၊ မူလပါဠိတော် သို့မဟုတ် မြန်မာပြန်တို့ကို Dynamic Tabs များဖြင့် စက္ကန့်ပိုင်းအတွင်း လဲလှယ်၍ စာပိုဒ်/အခန်းအလိုက် ဘေးချင်းယှဉ်တွဲ တစ်ပြိုင်နက် ဖတ်ရှုနိုင်ခြင်း။

### ၃။ ပါဠိ နှင့် မြန်မာပြန်/အဋ္ဌကထာ/ဋီကာ အပြန်အလှန် အမြန်ကူးပြောင်းနိုင်ခြင်း (Cross-Linking & Companion Dropdown)
- ပါဠိတော် ဖတ်ရှုနေစဉ် အပေါ်ဘားရှိ **"🇲🇲 မြန်မာပြန်သို့"** ခလုတ်ကို နှိပ်လိုက်ရုံဖြင့် အဆိုပါစာပိုဒ်နှင့် ကိုက်ညီသော မြန်မာပြန်စာမျက်နှာသို့ တိုက်ရိုက်ရောက်ရှိသွားခြင်း။
- မြန်မာပြန် ဖတ်ရှုနေစဉ် အပေါ်ဘားရှိ **"☸️ ပါဠိတော်သို့"** ခလုတ်ကို နှိပ်လိုက်ရုံဖြင့် မူရင်းပါဠိတော် စာမျက်နှာသို့ တိုက်ရိုက် ပြန်လည်ရောက်ရှိခြင်း။
- အပေါ်ဘားရှိ **"တွဲဖက်ကျမ်း"** ခလုတ်မှတစ်ဆင့် ဆက်စပ် အဋ္ဌကထာ၊ ဋီကာ၊ မူလကျမ်းစာများကို Split-View ဖြင့် ယှဉ်တွဲဖတ်ရှုခြင်း သို့မဟုတ် ထိုကျမ်းစာအုပ်ဆီသို့ တိုက်ရိုက်ကူးပြောင်းဖတ်ရှုနိုင်ခြင်း။

### ၄။ ပါဠိ-မြန်မာ အဘိဓာန် အပြန်အလှန် ရှာဖွေမှု (Instant Click-to-Lookup)
- စာဖတ်နေစဉ် မသိသော ပါဠိစာလုံး တစ်လုံးချင်းစီကို **Click နှိပ်လိုက်ရုံဖြင့်** အဘိဓာန် ၈ မျိုးလုံးမှ အဓိပ္ပာယ် ချက်ချင်း ထွက်ပေါ်လာခြင်း။
- ပါဠိ ဝိဘတ်ဖြုတ်နည်း (Pali Stemming) ပါဝင်သဖြင့် `ဗုဒ္ဓေါ`၊ `ဓမ္မဿ`၊ `သမ္မာသမ္ဗုဒ္ဓဿ` စသည်တို့ကိုလည်း မူရင်းပုဒ်၏ အနက်ကို ရှာဖွေပေးခြင်း။

### ၅။ အလွန်လျင်မြန်သော Full-Text Word & Sutta Search (ရှာဖွေမှုစနစ်)
- ပါဠိစာလုံးပေါင်း **၉၂၃,၆၉၅ လုံး**၊ သုတ္တန်ပေါင်း **၆,၈၈၁ ပုဒ်**၊ မြန်မာပြန် မာတိကာပေါင်း **၁၃,၈၄၈ ခု** အတွင်း မီလီစက္ကန့်ပိုင်းအတွင်း ရှာဖွေနိုင်ခြင်း။

### ၆။ မျက်စိအေးစေသော Themes ၃ မျိုး နှင့် Font Size ချိန်ညှိမှု
- 📜 စက္ကူရောင် (Paper Mode - Warm Parchment)
- ☀️ နေ့ရောင် (Day Mode)
- 🌙 ညရောင် (Dark Mode)

### ၇။ စာမျက်နှာနှင့် ရှာဖွေမှု အလိုအလျောက် မှတ်တမ်းစနစ် (Reading & Search History)
- Browser ၏ LocalStorage ကို အသုံးပြုပြီး ဖွင့်ဖတ်သမျှ စာအုပ်များ၊ စာမျက်နှာများနှင့် ရှာဖွေမှုများကို အလိုအလျောက် ရက်စွဲအလိုက် စနစ်တကျ မှတ်တမ်းတင်ပေးထားခြင်း။
- `ယနေ့`၊ `မနေ့က`၊ `လွန်ခဲ့သော ၇ ရက်အတွင်း` စသည်ဖြင့် စနစ်တကျ အုပ်စုဖွဲ့ပြသပြီး ခလုတ်တစ်ချက်နှိပ်ရုံဖြင့် မူလဖတ်ရှုခဲ့သည့် Mode နှင့် စာမျက်နှာသို့ တိုက်ရိုက် ပြန်လည်ရောက်ရှိနိုင်ခြင်း။

### ၈။ ကွန်ပျူတာ အမြန်သုံး Keyboard Shortcuts (Hotkeys)
- `[` / `]` သို့မဟုတ် `◀` / `▶` : ယခင်/နောက် စာမျက်နှာသို့ လှန်ရန်
- `Ctrl + K` သို့မဟုတ် `/` : တိပိဋက စာလုံးပေါင်းစုံ ရှာဖွေရန် (Universal Search)
- `Ctrl + H` သို့မဟုတ် `H` : ဖတ်ရှုမှုနှင့် ရှာဖွေမှု မှတ်တမ်း (History) ဖွင့်ရန်
- `F11` : မျက်နှာပြင်ပြည့် / အာရုံစူးစိုက်ဖတ်ရှုရန် (Zen / Focus Mode) ဖွင့်/ပိတ်
- `Esc` : Focus Mode မှ ထွက်ရန် သို့မဟုတ် မည်သည့် Modal / Popup မဆို ပိတ်ရန်

### ၉။ မျက်နှာပြင်ပြည့်နှင့် အာရုံစူးစိုက် စာဖတ်မုဒ် (Zen / Focus Fullscreen Reading Mode)
- စာဖတ်နေစဉ် မျက်စိရှင်းလင်းစွာ အာရုံစူးစိုက်ဖတ်ရှုနိုင်ရန် Header၊ Menu bar များနှင့် Browser URL bar များကို ခဏဖျောက်ပေးထားမည့် စစ်မှန်သော မျက်နှာပြင်ပြည့်စနစ်။
- စာဖတ်မျက်နှာပြင် လွတ်ရာနေရာကို ပေါ့ပေါ့ပါးပါး တစ်ချက်ပုတ် (Tap) လိုက်ရုံဖြင့် ဘားများ ပုန်း/ပေါ် ချောမွေ့စွာ ပြောင်းလဲနိုင်ခြင်း (Kindle / Apple Books ပုံစံ) နှင့် `✕ ပုံမှန်မြင်ကွင်း` Floating Button ပါဝင်ခြင်း။

## ✨ ထပ်မံဖြည့်စွက် ပြုပြင်ပြီးစီးမှုများ (Recent Updates & Enhancements)

### ၁။ ဆဋ္ဌမူစာအုပ် မူရင်းအတိုင်း ဂါထာပါဠိတော်များ သတ်ပုံသန့်စင်ခြင်း (Authentic Chatthasangayana Gāthā Typography)
- **ဂါထာအစ/အဆုံး Quotation Marks (‘‘, ’’, “, ”) များ မပါရှိစေဘဲ သန့်စင်ခြင်း:** ဆဋ္ဌသင်္ဂါယနာ မူရင်းစာအုပ်ကြီးအတိုင်း ဂါထာများ၏ အစနှင့် အဆုံးတွင် quotation marks များ မပါရှိစေဘဲ မူရင်းအတိုင်း သန့်စင်ဖယ်ရှားပေးခြင်း (ဥပမာ - `‘‘အဘိက္ကန္တေန ဝဏ္ဏေန၊` အစား `အဘိက္ကန္တေန ဝဏ္ဏေန၊`၊ `ပဘာသတီ’’တိ။` အစား `ပဘာသတီတိ။`၊ `သဟဗျတ’’န္တိ။` အစား `သဟဗျတန္တိ။` ဟု တိကျသပ်ရပ်စွာ ပြသပေးခြင်း)။ စကားလုံးကြား ဆန္ဒိအဖြုတ် (Sandhi Elision Apostrophe - ဥပမာ `ကေန တေ'တာဒိသော ဝဏ္ဏော`) ကိုမူ မူရင်းအတိုင်း မပျက်မစီး အပြည့်အဝ ထိန်းသိမ်းထားရှိပေးခြင်း။
- **ဆဋ္ဌမူ ပုဒ်ထီး ( ၊ ) နှင့် ပုဒ်မ ( ။ ) စနစ်:** ဂါထာပါဠိတော်များအားလုံးတွင် အင်္ဂလိပ်ကော်မာများအစား ဆဋ္ဌမူစာအုပ် မူရင်းအတိုင်း **ပထမပုဒ်နှင့် တတိယပုဒ်အဆုံးတွင် ပုဒ်ထီး ( ၊ )**၊ **ဒုတိယပုဒ်နှင့် စတုတ္ထပုဒ်အဆုံးတွင် ပုဒ်မ ( ။ )** အဖြစ် Server (Python API) နှင့် Frontend (Web UI) နှစ်ဘက်စလုံးမှ အလိုအလျောက် တိကျစွာ ပြောင်းလဲပေးခြင်း။
  ```
  (နမူနာ - ဓမ္မပဒ အပ္ပမာဒဝဂ် ဂါထာ ၂၁)
  ၂၁။ အပ္ပမာဒေါ အမတပဒံ၊ ပမာဒေါ မစ္စုနော ပဒံ။
      အပ္ပမတ္တာ န မီယန္တိ၊ ယေ ပမတ္တာ ယထာ မတာ။
  ```
- စကားပြေ (Bodytext / Prose) များတွင် မလိုအပ်သော English comma များကို သန့်စင်ဖယ်ရှားပေးခြင်း။

### ၂။ ဆဋ္ဌမူ ပေယျာလ အကျဉ်းချုံး သင်္ကေတများ (Authentic Peyāla Formatting)
- အရင်စာပိုဒ်နှင့်တူသော အကျဉ်းချုံးနေရာများ (`...ပ...` သို့မဟုတ် `…ပေ…`) ကို ဆဋ္ဌမူစာအုပ် မူရင်းအတိုင်း **`။ ပ ။`** အဖြစ် ပါဠိတော်နှင့် မြန်မာပြန် နှစ်မျိုးလုံးတွင် စနစ်တကျ ပြောင်းလဲပြသပေးခြင်း။
  ```
  (နမူနာ - ဝိမာနဝတ္ထု ဂါထာ ၂၄၉)
  ၂၄၉။ သာ ဒေဝတာ အတ္တမနာ။ ပ ။ ယထာ ကမ္မဿိဒံ ဖလံ။
  ```

### ၃။ စဉ်ဆက်မပြတ် ဆက်တိုက်ဖတ်ရှုနိုင်ခြင်း (Continuous Stream Feed / Facebook-Style Scroll)
- **Desktop တွင်:** Mouse Wheel ကို အောက်သို့ ဆက်တိုက်လှိမ့်သွားရုံဖြင့် စာမျက်နှာ (၁)၊ (၂)၊ (၃) စသည်ဖြင့် စဉ်ဆက်မပြတ် ဆက်တိုက်ထွက်ပေါ်လာခြင်း။
- **Mobile တွင်:** လက်ချောင်းဖြင့် အပေါ်သို့ ပုံမှန်အတိုင်း အပေါ်သို့ ဆွဲတင်ဖတ်ရှုနိုင်ခြင်း။
- စာဖတ်သူ၏ စိတ်ကြိုက်အလိုက် **"စာမျက်နှာ ဆက်တိုက်" (Feed Mode)** သို့မဟုတ် **"စာမျက်နှာ တစ်မျက်နှာချင်း" (Single Page Mode)** ကို ခလုတ်တစ်ချက်နှိပ်ရုံဖြင့် လွတ်လပ်စွာ ပြောင်းလဲဖတ်ရှုနိုင်ခြင်း။

### ၄။ ကျမ်းပေါင်းချုပ် စာအုပ်များ၏ မူရင်း စာမျက်နှာနယ်နိမိတ်များ အပြည့်အဝ ထိန်းသိမ်းခြင်း (Multi-Treatise Volume Page Boundaries)
- စာအုပ်တစ်အုပ်တည်းတွင် ကျမ်းစာပေါင်းများစွာ ပေါင်းစည်းထားသော ကျမ်းများ (ဥပမာ- ခုဒ္ဒကနိကာယ် ကျမ်းများ၊ အဘိဓမ္မာ ညဝါကျမ်းများ) တွင် စာမျက်နှာ ၁ မှ မဟုတ်ဘဲ မူရင်းစာအုပ် စာမျက်နှာအလိုက် (ဥပမာ- ထေရီဂါထာ စာမျက်နှာ ၃၇၇ မှ စတင်ခြင်း) မူရင်းအတိုင်း တိကျစွာ ဖွင့်လှစ်နိုင်ခြင်း။

### ၅။ မူရင်း Android APK အတိုင်း လှပသော ပင်မမာတိကာကြီးနှင့် Mobile Navigation Bar
- **ပင်မစာမျက်နှာ (Home):** မူရင်း Android APK ကဲ့သို့ သပ်ရပ်သော နိကာယ်/ကဏ္ဍအလိုက် မာတိကာကတ်ပြားကြီးများ။
- **Mobile Bottom Nav:** ဖုန်းစခရင်များတွင် အသုံးပြုရ အလွန်လွယ်ကူသော Floating Bottom Navigation Bar (စာအုပ်စင်၊ မာတိကာ၊ ရှာဖွေမှု၊ အဘိဓာန်၊ အခြား)။
- **အစဆုံးဝင်ရောက်ချိန် ပင်မမာတိကာ ပွင့်လှစ်ခြင်း:** App သို့ စတင်ဝင်ရောက်ချိန်တွင် စာဖတ်မျက်နှာပြင် မရှုပ်ထွေးစေဘဲ အမြဲတမ်း သန့်ရှင်းသော ပင်မကျမ်းစာမာတိကာကတ်ပြားကြီးများဖြင့် အစပြုနိုင်ရန် စီမံထားခြင်း။

### ၆။ စာကြောင်းအကူးအပြောင်းတွင် စာလုံးဆင့်များ ပြတ်တောက်၍ (+) ဝိရာမသင်္ကေတ မဖြစ်ပေါ်စေရန် အမြစ်ပြတ် ဖြေရှင်းခြင်း (Line-Break Virama Conjunct Fix)
- **ပြဿနာ:** မြန်မာစာ/ပါဠိတော် ယူနီကုဒ်တွင် စာလုံးဆင့် (ဥပမာ `ဘဂဝန္တာနံ`, `သာရိပုတ္တော`, `ဗြဟ္မစရိယံ`, `စိရဋ္ဌိတိကံ`) များကို Browser (Chromium / WebKit) များက စာကြောင်းအဆုံးသို့ ရောက်သောအခါ စာလုံးဆင့်အလယ် (`\u1039` virama အဆုံး) မှ ဖြတ်ချလိုက်ခြင်းကြောင့် အပေါ်စာကြောင်းအဆုံး၌ ဝိရာမ Fallback သင်္ကေတ အပေါင်းလက္ခဏာ **`+` (`₊`)** ဖြစ်ပေါ်နေခဲ့ခြင်း။ (မူရင်းဆော့ဝဲလ်၏ `help.html` လမ်းညွှန်တွင်ပါ Android WebView ၏ အားနည်းချက်အဖြစ် မှတ်တမ်းတင်ထားခဲ့ရသော ပြဿနာဖြစ်ပါသည်)။
- **ဖြေရှင်းချက်:** ပါဠိတော်နှင့် မြန်မာပြန်ရှိ စာလုံးများနှင့် စာလုံးဆင့်များအားလုံးကို `white-space: nowrap` ပါရှိသော စနစ်ဖြင့် လုံခြုံစွာ ထိန်းကျောင်းပေးလိုက်သောကြောင့် စာကြောင်းခေါက်ရာတွင် မည်သည့်အခါမှ စာလုံးဆင့်ကြားမှ ဖြတ်မချတော့ဘဲ စာလုံးတစ်လုံးလုံး ညီညီညာညာ အောက်ကြောင်းသို့ ဆင်းသွားသဖြင့် `+` လုံးဝမဖြစ်ပေါ်တော့ပါ။

### ၇။ ယှဉ်တွဲဖတ်ရှုမှု စနစ် (Dual Split View) ၏ အဆင့်မြင့် စာမျက်နှာ/စာပိုဒ် ချိန်ညှိမှု စနစ်များ (Advanced Split-View Controls)
- **သီးခြား စာမျက်နှာလှန်ခလုတ်များ (Independent Left/Right Controls):** ပါဠိတော်ဘက်ခြမ်းနှင့် မြန်မာပြန်ဘက်ခြမ်းတို့တွင် သီးခြား စာမျက်နှာရှေ့တိုး/နောက်ဆုတ်ခလုတ်များ (`◀ စာ [X] / [Y] ▶`) နှင့် စာမျက်နှာရိုက်ထည့်ခလုတ်များ ပါဝင်သဖြင့် ပါဠိတော်နှင့် မြန်မာပြန် စာမျက်နှာမညီသည့်အခါ လွတ်လပ်စွာ ချိန်ညှိဖတ်ရှုနိုင်ခြင်း။
- **အပြန်အလှန် စာပိုဒ်ကလစ်နှိပ် ခုန်ကူးခြင်း (Interactive Paragraph Sync & Pulse Highlight):** ပါဠိတော်ဘက်မှ စာပိုဒ်နံပါတ် (ဥပမာ `၁၇။`) ကို ကလစ်နှိပ်ပါက မြန်မာပြန်ဘက်ရှိ ထိုစာပိုဒ်ဆီသို့ အလိုအလျောက် scroll ဆွဲပေးပြီး highlight လင်းလက်ပြသပေးခြင်း (မြန်မာပြန်မှ အပိုဒ်နံပါတ်ကို နှိပ်ပါကလည်း ပါဠိတော်ဆီသို့ ခုန်ကူးပြသခြင်း)။
- **တစ်ပြိုင်တည်း ညှိယူပေးသော ခလုတ် (Sync Matching Pages Button):** စာမျက်နှာများ လွတ်လပ်စွာ လှန်ထားသော်လည်း မူလကိုက်ညီသော စာမျက်နှာသို့ တစ်ချက်နှိပ်ရုံဖြင့် အချိန်မရွေး ပြန်လည်ညီညာစေခြင်း။
- **Majority Paragraph Voting Algorithm:** စာမျက်နှာတစ်ခုတွင် စာပိုဒ်များစွာ ပါဝင်နေပါက အများဆုံးပါဝင်သော စာမျက်နှာကို Server က အလိုအလျောက် တိကျစွာ ရွေးချယ်ချိတ်ဆက်ပေးခြင်း။

### ၈။ ဂါထာစာကြောင်း အစ/အဆုံး ညီညီညာညာ ညှိယူပေးခြင်း (Gāthā Line Alignment)
- ဂါထာစာပိုဒ်များ၏ စာကြောင်းအစရှိ မညီမညာဖြစ်နေသော space များကို အလိုအလျောက် ရှင်းလင်းပေးပြီး၊ ပထမ/တတိယ/ဒုတိယ/စတုတ္ထပုဒ်များ စာကြောင်းအစအဆုံး တညီတညာတည်း သပ်ရပ်စွာ ပေါ်လွင်စေခြင်း။

### ၉။ ကလစ်တစ်ချက်နှိပ် အဘိဓာန်ရှာဖွေမှု (Word Click Lookup) ပိုမိုတိကျမြန်ဆန်ခြင်း
- ပါဠိစာလုံးများကို သီးခြား token အဖြစ် စနစ်တကျ wrap လုပ်ထားသဖြင့် စာဖတ်နေစဉ် မည်သည့် ပါဠိစာလုံးပေါ်မဆို ကလစ်နှိပ်လိုက်သည်နှင့် ချက်ချင်းတိကျစွာ ဖမ်းယူ၍ အဘိဓာန် ဖွင့်လှစ်ပေးနိုင်ခြင်း။

### ၁၀။ Mobile View တွင် ဂါထာတော်များ တစ်ပါဒ တစ်ကြောင်းစီ အချိုးကျ ပြသခြင်း (Mobile Gāthā Couplet & Pāda Formatting)
- **Desktop တွင်:** ကျယ်ဝန်းသော စခရင်အရွယ်အစားအရ ပထမနှင့် ဒုတိယပါဒ၊ တတိယနှင့် စတုတ္ထပါဒ စသည်ဖြင့် အတွဲလိုက် (Couplets) ဘေးချင်းကပ်လျက် ဆဋ္ဌမူစာအုပ် မူရင်းအတိုင်း သပ်ရပ်စွာ ပေါ်လွင်ခြင်း။
- **Mobile နှင့် Split View တွင်:** ဖုန်းစခရင်ကဲ့သို့ နေရာကျဉ်းသော အခါများ၌ စာကြောင်းအလယ်မှ စာလုံးများ မညီမညာ ဖြတ်မကျဘဲ ဂါထာ၏ အပိုဒ်/ဆန်း အလှအပအတိုင်း **တစ်ပါဒ ပြီးလျှင် နောက်တစ်ကြောင်းတွင် တစ်ပါဒ (တစ်ပါဒ တစ်ကြောင်း)** စီ သီးခြားစီ ညီညီညာညာ ဖတ်ရှုနိုင်အောင် စနစ်တကျ ခွဲထုတ်ပြသပေးခြင်း။

### ၁၁။ အဆင့်မြင့် ဖတ်ရှုမှုနှင့် ရှာဖွေမှု မှတ်တမ်းစနစ် (Modern LocalStorage Reading & Search History)
- **အလိုအလျောက် မှတ်တမ်းတင်ခြင်း:** ပါဠိတော်၊ မြန်မာပြန်၊ ယှဉ်တွဲဖတ်ရှုမှု (Split View) စာမျက်နှာ ဖွင့်ဖတ်သမျှနှင့် ပါဠိ/မြန်မာ/အဘိဓာန် ရှာဖွေမှုများကို LocalStorage စနစ်ဖြင့် မိမိ Browser အတွင်း အလိုအလျောက် သိမ်းဆည်းပေးခြင်း။
- **ရက်စွဲအလိုက် စနစ်တကျ အုပ်စုဖွဲ့ပြသခြင်း:** Chrome/Safari Browser History ကဲ့သို့ `ယနေ့ (Today)`၊ `မနေ့က (Yesterday)`၊ `လွန်ခဲ့သော ၇ ရက်အတွင်း`၊ `လွန်ခဲ့သော ရက် ၃၀ အတွင်း`၊ `ယခင်လများက` ဟူ၍ ရက်စွဲအလိုက် အချိန်အတိအကျနှင့်တကွ သပ်ရပ်စွာ အုပ်စုဖွဲ့ ပြသပေးခြင်း။
- **ခလုတ်တစ်ချက်နှိပ်ရုံဖြင့် မူလနေရာသို့ တိုက်ရိုက်ပြန်ရောက်ခြင်း:** မှတ်တမ်းစာရင်းရှိ မည်သည့် ကျမ်းစာကိုမဆို ကလစ်နှိပ်လိုက်သည်နှင့် ထိုစဉ်က ဖတ်ရှုခဲ့သည့် Mode (ပါဠိ/မြန်မာ/ယှဉ်တွဲ)၊ စာအုပ်အမည်နှင့် စာမျက်နှာဆီသို့ ချက်ချင်း အဆင်သင့် ဖွင့်လှစ်ပေးခြင်း။
- **ရှာဖွေမှုမှတ်တမ်း (Search History):** ပါဠိစကားလုံး၊ သုတ္တန်၊ ကျမ်းစာအုပ်၊ အဘိဓာန် ရှာဖွေခဲ့မှုများကို သီးခြား Tab ဖြင့် မှတ်တမ်းတင်ထားပြီး ကလစ်နှိပ်ရုံဖြင့် မူလရှာဖွေမှုရလဒ်များကို ချက်ချင်း ပြန်လည်ရှာဖွေပြသပေးခြင်း။
- **မှတ်တမ်းအတွင်း အမြန်ရှာဖွေခြင်းနှင့် စစ်ထုတ်ခြင်း:** ကျမ်းစာအမည်၊ အခန်း၊ စာမျက်နှာအလိုက် ရှာဖွေနိုင်ပြီး ပါဠိ/မြန်မာပြန်/ယှဉ်တွဲဖတ် mode အလိုက် သီးခြား Filter Pills ဖြင့် စစ်ထုတ်ကြည့်ရှုနိုင်ခြင်း။
- **သီးခြားမှတ်တမ်း ဖျက်ခြင်းနှင့် အားလုံးရှင်းလင်းခြင်း:** မလိုအပ်သော မှတ်တမ်းတစ်ခုချင်းစီကို အမှိုက်ပုံးခလုတ်ဖြင့် ဖျက်နိုင်သလို၊ မှတ်တမ်းအားလုံးကိုလည်း Confirm Dialog ဖြင့် လုံခြုံစွာ ရှင်းလင်းနိုင်ခြင်း။
- **အလွယ်တကူ ဝင်ရောက်နိုင်သော နည်းလမ်းများ:** Mobile Bottom Nav Bar ရှိ `မှတ်တမ်း` ခလုတ်၊ Desktop Header ရှိ `မှတ်တမ်း` ခလုတ်၊ Mobile Drawer ထဲရှိ ခလုတ်၊ နှင့် Keyboard Shortcut `Ctrl + H` သို့မဟုတ် `H` (စာမရိုက်ချိန်) နှိပ်ရုံဖြင့် အချိန်မရွေး ဖွင့်လှစ်နိုင်ခြင်း။

### ၁၂။ Profile Backup / Restore နှင့် ဓမ္မစာပေ ဖတ်ရှုလေ့လာမှု စာရင်းအင်း (Data Backup/Restore & Dhamma Reading Insights)
- **JSON Profile Backup & Restore စနစ်:**
  - ဖတ်ရှုခဲ့မှု မှတ်တမ်းများ (Reading History)၊ ရှာဖွေမှု မှတ်တမ်းများ (Search History)၊ စာညှပ်မှတ်စုများ (Bookmarks) နှင့် အသုံးပြုသူ၏ Theme၊ စာလုံးအရွယ်အစား၊ Feed/Single Scroll Mode ဆက်တင်များကို တစ်ပါတည်း JSON ဖိုင် (`tipitaka-backup-YYYY-MM-DD.json`) အဖြစ် Download ရယူ သိမ်းဆည်းနိုင်ခြင်း (💾 Backup)။
  - အခြား ဖုန်း/ကွန်ပျူတာ သို့မဟုတ် Browser အသစ်များသို့ ပြောင်းရွှေ့သည့်အခါ Backup ဖိုင်ကို တစ်ချက်နှိပ်ရုံဖြင့် မူလမှတ်တမ်း၊ မှတ်စုနှင့် ဆက်တင်များအားလုံး အလိုအလျောက် ပေါင်းစပ်တင်သွင်းပေးနိုင်ခြင်း (📥 Restore)။
- **ဓမ္မစာပေ ဖတ်ရှုလေ့လာမှု စာရင်းအင်း (Dhamma Reading Insights):**
  - **📖 ယခုအပတ် ဖတ်ရှုမှု စုစုပေါင်း (Weekly Activity):** ယခုအပတ်နှင့် ယနေ့ ဖတ်ရှုလေ့လာခဲ့သော အကြိမ်ရေများ။
  - **☸️ အများဆုံး လေ့လာသော ပိဋကတ် (Top Explored Pitaka):** သုတ္တန်၊ ဝိနည်း၊ အဘိဓမ္မာ သို့မဟုတ် အဋ္ဌကထာ/ဋီကာ စသည်ဖြင့် မည်သည့် ပိဋကတ်တော်ကို အများဆုံး လေ့လာဖတ်ရှုနေသည်ကို အလိုအလျောက် တွက်ချက်ဖော်ပြခြင်း။
  - **📚 စုစုပေါင်း လေ့လာခဲ့မှု နှင့် ရှာဖွေမှုများ:** ဖွင့်လှစ်ဖတ်ရှုခဲ့သော စာမျက်နှာ စုစုပေါင်းနှင့် စကားလုံး/သုတ္တန် ရှာဖွေမှု အကြိမ်ရေများ။
  - **⏱️ နောက်ဆုံး လေ့လာခဲ့ချိန် (Last Active Time):** အနီးစပ်ဆုံး နောက်ဆုံး ဖတ်ရှုခဲ့သည့် အချိန်နှင့် ရက်စွဲ။
  - **🏆 အများဆုံး ဖတ်ရှုလေ့လာဖြစ်သော ထိပ်တန်းကျမ်းစာအုပ် ၅ အုပ် (Top 5 Books Ranking):** Visual Percentage Progress Bar ဖြင့် အများဆုံး ဖတ်ရှုဖြစ်သော ကျမ်းစာ ၅ အုပ်ကို အဆင့်လိုက် ဖော်ပြပေးခြင်း။

### ၁၃။ မာတိကာ ခေါင်းစဉ်နှင့် စာမျက်နှာ အချိန်နှင့်တပြေးညီ ညွှန်ပြမှုစနစ် (Real-Time TOC & Reading Progress Tracker - Desktop & Mobile)
- **ကျမ်းစာအုပ် ရွေးချယ်လိုက်သည်နှင့် မာတိကာ တိုက်ရိုက်ပွင့်သော စနစ် (Default Reader View):**
  - Home Catalog သို့မဟုတ် Sidebar စာရင်းမှ ကျမ်းစာအုပ်တစ်အုပ်ကို နှိပ်လိုက်သည်နှင့် Reader သို့ ကူးပြောင်းချိန်တွင် ဘယ်ဘက် Sidebar ကို အလိုအလျောက် ဖွင့်ပေးပြီး 'မာတိကာ' (TOC) Tab ကို Sticky Current Chapter Card နှင့်တကွ အဆင်သင့် ညွှန်ပြပြသပေးခြင်း။
- **ဘယ်ဘက် မာတိကာ စာရင်းတွင်း ရောက်ရှိနေရာ အလိုအလျောက် အလင်းရောင်ထိုးပြသခြင်း (Active TOC Highlight & Auto-Scroll):**
  - ပါဠိတော် သို့မဟုတ် မြန်မာပြန် ကျမ်းစာမျက်နှာများကို ဖတ်ရှုနေစဉ် ရောက်ရှိနေသော စာမျက်နှာနှင့် ကိုက်ညီသည့် မာတိကာခေါင်းစဉ်ကို လိမ္မော်ရောင် Highlight အလင်းတန်း၊ ဘေးဘောင်မျဉ်းနှင့် လင်းလက်နေသော အမှတ်အသားစက်ဝိုင်း (`pulsing dot`) ဖြင့် ထင်ရှားစွာ ပြသပေးခြင်း။
  - မာတိကာ စာရင်းရှည်လျားနေသော်လည်း စာဖတ်သူ ရောက်ရှိနေသော အခန်းကို မျက်စိရှေ့တည့်တည့်သို့ အလိုအလျောက် ချောမွေ့စွာ ရွှေ့ပြောင်းပေးခြင်း (`Smooth Scroll into View`)။
- **မာတိကာထိပ်ရှိ လက်ရှိဖတ်ရှုနေသော အခန်း ကတ်ပြား (Sticky Current Chapter Card):**
  - မာတိကာ Tab ၏ ထိပ်ဆုံးတွင် `📖 လက်ရှိ ရောက်ရှိ မာတိကာ` ကတ်ပြား ပါရှိပြီး၊ လက်ရှိဖတ်နေသော အခန်းအမည်၊ စာမျက်နှာ အပိုင်းအခြား (ဥပမာ `စာမျက်နှာ ၁ မှ ၁၂ အထိ`) နှင့် လက်ရှိရောက်ရှိ စာမျက်နှာတို့ကို အမြဲတမ်း ရှင်းလင်းစွာ ဖော်ပြထားခြင်း။ ထိုကတ်ပြားကို ကလစ်နှိပ်ပါကလည်း မာတိကာစာရင်းရှိ ထိုအခန်းဆီသို့ တိုက်ရိုက် လင်းလက်ခုန်ကူးပေးခြင်း။
- **Mobile View တွင် အောက်စာမျက်နှာများသို့ ရောက်ရှိသော်လည်း အမြဲကပ်နေသော Sticky Floating Breadcrumb Bar:**
  - ဖုန်းစခရင်များတွင် Header နေရာကျဉ်းမြောင်းသဖြင့် စာဖတ်မျက်နှာပြင်၏ ထိပ်တွင် `📖 ပါရာဇိကပါဠိ • ၁။ ဝေရဉ္ဇကဏ္ဍ   စာ-၁ ❯` စာတန်းပါသော Touch-friendly Breadcrumb Card ကို ထည့်သွင်းထားခြင်း။
  - အောက်စာမျက်နှာများသို့ မည်မျှပင် scroll ဆင်းသွားစေကာမူ ကဒ်ပြားသည် စခရင်အပြင်သို့ လျှောတက်ပျောက်ကွယ်မသွားဘဲ အပေါ်ထိပ်တွင် Sticky Floating Bar အဖြစ် အမြဲတမ်း ပေါ်နေပြီး၊ စာမျက်နှာ ၂၊ ၃ သို့ ရောက်ရှိသွားပါကလည်း စာမျက်နှာနံပါတ်နှင့် အခန်းခေါင်းစဉ်ကို Live အလိုအလျောက် ပြောင်းလဲဖော်ပြပေးခြင်း။
  - မည်သည့်နေရာမှမဆို ဤ Breadcrumb Bar ကို လက်ချောင်းဖြင့် တစ်ချက်တို့လိုက်ရုံဖြင့် မာတိကာ Drawer ပွင့်လာပြီး လက်ရှိရောက်ရှိနေသော အခန်းဆီသို့ တိုက်ရိုက် ရောက်ရှိစေခြင်း။
- **Header နှင့် စာမျက်နှာ ကြားခံ Divider များတွင် မာတိကာခေါင်းစဉ် ထည့်သွင်းခြင်း:**
  - ကွန်ပျူတာ Header ရှိ စာအုပ်အမည်ဘေးတွင် မာတိကာခေါင်းစဉ် အချိန်နှင့်တပြေးညီ ပေါ်လွင်နေပြီး၊ ကလစ်နှိပ်ပါက မာတိကာသို့ တိုက်ရိုက်ကူးပြောင်းနိုင်ခြင်း။
  - Continuous Feed mode တွင် စာမျက်နှာတစ်ခုနှင့် တစ်ခုကြားရှိ ခေါင်းစီး Divider တွင် `📖 ဝေရဉ္ဇကဏ္ဍ • စာမျက်နှာ ၄` ဟူ၍ အခန်းအမည်ပါ တစ်ပါတည်း ထည့်သွင်းပြသပေးခြင်း။

### ၁၄။ စစ်မှန်သော မျက်နှာပြင်ပြည့်နှင့် အာရုံစူးစိုက် စာဖတ်မုဒ် (Zen / Focus Fullscreen Reading Mode with Tap-to-Toggle)
- **စစ်မှန်သော မျက်နှာပြင်ပြည့်စနစ် (True Native Fullscreen + Distraction-Free UI):**
  - ဖုန်းစခရင်များတွင် နေရာယူထားသော Browser ၏ URL Address Bar ရော၊ အက်ပ်၏ ခေါင်းစဉ် Header နှင့် အောက်ခြေ Bottom Nav Bar များကိုပါ ချောမွေ့စွာ ခဏဖျောက်ပေးထားမည့် စနစ်။
  - ဖုန်းမျက်နှာပြင် တစ်ခုလုံးတွင် မူရင်းကျမ်းစာမျက်နှာ သက်သက်သာ ၁၀၀% ပြည့်ဝစွာ ရှင်းလင်းစွာ ပေါ်နေစေပြီး မူရင်းကျမ်းစာအုပ်ကြီးကို ဖတ်ရှုနေရသကဲ့သို့ ငြိမ်သက်အေးချမ်းသော Pure Reading Experience ကို ရရှိစေခြင်း။
- **စာမျက်နှာကို ထိ၍ ဘားများ ပိတ်/ဖွင့်ခြင်း (Tap-to-Toggle Controls):**
  - Focus Mode ဝင်ရောက်နေချိန်တွင် စာဖတ်မျက်နှာပြင် လွတ်ရာနေရာကို ပေါ့ပေါ့ပါးပါး တစ်ချက်ပုတ် (Tap) လိုက်ရုံဖြင့် အပေါ် Header နှင့် အောက်ခြေ Menu Bar များ ပြန်လည် ပေါ်ထွက်လာခြင်း (Unhide)။
  - နောက်တစ်ကြိမ် ထပ်ပုတ်လိုက်ပါက (သို့မဟုတ် စာဖတ်ရင်း scroll ဆင်းလိုက်ပါက) ဘားများ အလိုအလျောက် ပြန်လည် ပုန်းလျှိုးသွားခြင်း (Kindle / Apple Books ပုံစံ)။
- **အလွယ်တကူ ပြန်ထွက်နိုင်သော Floating Mini Button (`✕ ပုံမှန်မြင်ကွင်း`):**
  - Focus Mode ဝင်နေစဉ် စာဖတ်သူ၏ မျက်စိကို မနှောင့်ယှက်စေဘဲ စခရင် ထောင့်ဘက်တွင် သေးသွယ်မှိန်ပြပြ အလင်းရောင်ရှိသော `✕ ပုံမှန်မြင်ကွင်း` Floating Button လေး ပေါ်နေပြီး၊ တစ်ချက်နှိပ်လိုက်ရုံဖြင့် မူလပုံမှန်စနစ်သို့ ချက်ချင်း ပြန်လည်ရောက်ရှိနိုင်ခြင်း။
- **ဝင်ရောက်နိုင်သော နည်းလမ်းများစွာ (Multi-Trigger Options):**
  - Header အပေါ်ထိပ် ညာဘက်ရှိ `⛶ မျက်နှာပြင်ပြည့်` ခလုတ်
  - Mobile Drawer စာဖတ်ထိန်းချုပ်မှုများထဲရှိ `⛶ မျက်နှာပြင်ပြည့် ဖတ်ရှုရန် (Focus Mode)` ခလုတ်
  - ကွန်ပျူတာ Keyboard Shortcut `F11` (အဝင်/အထွက်) နှင့် `ESC` (အထွက်)

### ၁၅။ တွဲဖက်ကျမ်း ယှဉ်တွဲဖတ်ရှုမှု စနစ်သစ် (Dynamic Companion Split-View with Attha/Tika/MM Tabs & Auto Page Sync)
- **Dynamic Companion Tabs စနစ် (အဋ္ဌကထာ၊ ဋီကာ၊ မူလပါဠိတော်၊ မြန်မာပြန် Tabs များ):**
  - ယှဉ်တွဲဖတ်ရှုခြင်း (Dual Split View) ဖွင့်လှစ်လိုက်ချိန်တွင် ညာဘက်ခြမ်း၌ လက်ရှိကျမ်းစာနှင့် တိုက်ရိုက်ဆက်စပ်နေသော Companion Tab ခလုတ်များ (`[ 📖 အဋ္ဌကထာ ]`၊ `[ 📜 ဋီကာ ]`၊ `[ 🇲🇲 မြန်မာပြန် ]` သို့မဟုတ် အဋ္ဌကထာ/ဋီကာ ဖတ်နေချိန်တွင် `[ ☸️ မူလပါဠိ ]`) သက်ဆိုင်ရာ ကျမ်းရှိသည့်အတိုင်း dynamic အလိုအလျောက် ထွက်ပေါ်လာခြင်း။
  - ဘယ်ဘက်ခြမ်း စာမျက်နှာ မပျောက်ပျက်စေဘဲ ညာဘက်ခြမ်း Tab ခလုတ်ကို နှိပ်လိုက်ရုံဖြင့် အဋ္ဌကထာ၊ ဋီကာ နှင့် မြန်မာပြန်တို့ကို စက္ကန့်ပိုင်းအတွင်း လွတ်လပ်စွာ လဲလှယ်ဖတ်ရှုနိုင်ခြင်း။
- **စာပိုဒ်နှင့် စာမျက်နှာ အလိုအလျောက် ချိန်ညှိမှု (Smart Paragraph & Volume Synchronization):**
  - ဘယ်ဘက်ခြမ်းရှိ စာပိုဒ်နံပါတ် (`paranum`) အပေါ် မူတည်၍ ညာဘက်ခြမ်းသို့ ပြောင်းလိုက်သည်နှင့် ကိုက်ညီသော စာမျက်နှာသို့ အလိုအလျောက် ရောက်ရှိခြင်း (ဥပမာ- ပါရာဇိကပါဠိတော် စာမျက်နှာ ၁ ဖတ်နေစဉ် အဋ္ဌကထာသို့ ပြောင်းပါက နိဒါန်းပိုင်း ကျော်လွန်ပြီး စာပိုဒ် ၁ စတင်သော စာမျက်နှာ ၇၉ သို့လည်းကောင်း၊ ဋီကာသို့ ပြောင်းပါက စာမျက်နှာ ၁၉၅ သို့လည်းကောင်း အတိအကျ ကူးပြောင်းပေးခြင်း)။
- **အတွဲ ရွေးချယ်မှု စနစ် (Multi-Volume Selector):**
  - အဋ္ဌကထာ သို့မဟုတ် ဋီကာတွင် ပထမတွဲ၊ ဒုတိယတွဲ၊ တတိယတွဲ စသည်ဖြင့် အတွဲ ၂ တွဲ သို့မဟုတ် ၃ တွဲ ရှိပါက Volume Selector Dropdown အလိုအလျောက် ထွက်ပေါ်လာပြီး စာပိုဒ်အလိုက် အလိုအလျောက် အတွဲရွေးပေးခြင်း သို့မဟုတ် မိမိစိတ်ကြိုက် အတွဲရွေးချယ်နိုင်ခြင်း။
- **အပြန်အလှန် စာပိုဒ်ကလစ်နှိပ်ခြင်းနှင့် နှစ်ဖက်စလုံး အဘိဓာန် ထောက်ကူမှု (Bi-Directional Paragraph Sync & Right-Pane Dictionary):**
  - ညာဘက်ခြမ်းတွင် အဋ္ဌကထာ သို့မဟုတ် ဋီကာကို ဖတ်ရှုနေချိန်၌လည်း မသိသော ပါဠိစကားလုံးကို ကလစ်နှိပ်လိုက်ရုံဖြင့် အဘိဓာန်အဓိပ္ပာယ် ချက်ချင်း ထွက်ပေါ်လာခြင်း။ စာပိုဒ်နံပါတ်များကို ကလစ်နှိပ်ပါကလည်း တစ်ဖက်နှင့် တစ်ဖက် အပြန်အလှန် ခုန်ကူးပြသခြင်း။
- **အပေါ် Toolbar "တွဲဖက်ကျမ်း" Dropdown Menu သစ်:**
  - Header ရှိ `[ တွဲဖက်ကျမ်း ]` ခလုတ်ကို နှိပ်လိုက်ပါက ဆက်စပ် အဋ္ဌကထာ၊ ဋီကာ၊ မူလပါဠိတော်၊ မြန်မာပြန် ကျမ်းစာများကို ကတ်ပြားပုံစံဖြင့် ပြသပြီး `[ 📖 ယှဉ်တွဲဖတ်မည် ]` သို့မဟုတ် `[ ➔ ဖတ်မည် ]` ခလုတ်များဖြင့် တစ်ချက်နှိပ်ရုံဖြင့် တိုက်ရိုက် ရွေးချယ်ဖတ်ရှုနိုင်ခြင်း။
- **ဖုန်းများအတွက် Mobile Companion Drawer ခလုတ်:**
  - ဖုန်းစခရင်များတွင် ဘယ်ဘက် Drawer အတွင်း `[ 📚 တွဲဖက်ကျမ်းစာများ ရွေးချယ်ရန် ]` ခလုတ် ပါဝင်ပြီး နှိပ်လိုက်ပါက ဆက်စပ်ကျမ်းစာရွေးချယ်မှု Dialog ကို ချက်ချင်း ဖွင့်လှစ်ပေးခြင်း။

### ၁၆။ Header Toolbar Responsive ကျုံ့ဆန့်မှုနှင့် ညာဘက်အစွန်ခလုတ်များ မကျွံထွက်စေရန် စနစ်တကျ ပြင်ဆင်ခြင်း (Progressive Responsive Toolbar)
- Browser window အရွယ်အစားကို မည်မျှပင် ကျဉ်း/ကျယ် ပြုလုပ်စေကာမူ ညာဘက်ခြမ်းရှိ ခလုတ်များ အပြင်သို့ ကျွံမထွက်စေဘဲ စခရင်အကျယ်အလိုက် ၄ ဆင့်ခွဲ၍ စာသားများ အချိုးကျ ပုန်းကွယ်ပေးခြင်း (≤1720px, ≤1560px, ≤1380px, ≤1180px)။
- ကွန်ပျူတာ screen အမျိုးမျိုး၊ Split screen အနေအထားနှင့် Tablet များတွင် Toolbar ခလုတ်များ လုံးဝ အကွယ်အကွယ်မရှိဘဲ သပ်ရပ်စွာ ပေါ်လွင်အလုပ်လုပ်ခြင်း။

## 🚀 အသုံးပြုနည်း (How to Run)

## 🔄 VPS Server ပေါ်တွင် Update ပြုလုပ်နည်း (GitHub Workflow)

GitHub ပေါ်တွင် Code အသစ်များ ပြင်ဆင်ပြီးသည့်အခါတိုင်း VPS Terminal (SSH) သို့ ဝင်ရောက်ပြီး အောက်ပါ command များကို Run ပေးရုံဖြင့် ၂ စက္ကန့်အတွင်း Update ပြီးစီးပါသည် -

```bash
cd /opt/tipitaka
git pull origin main
sudo systemctl restart tipitaka
```

> **တစ်ကြောင်းတည်း အမြန် Run ရန်:**

## 🤖 နည်းပညာ တည်ဆောက်မှု နှင့် AI အကူအညီ (Development & AI Collaboration)

ဤ Web Application ကို ပြင်ဆင်အသုံးပြုသူ **Ashin Pannasetthalankara** သည် Web Development နည်းပညာကို အခြေခံမျှသာ သိရှိနားလည်သူ ဖြစ်သည့်အတွက်၊ ဤစနစ်ကြီးတစ်ခုလုံး၏ -
- **Backend Architecture:** Python (Flask), SQLite Database optimizations, Multi-book indexing, Cache-Control and API endpoints
- **Frontend Modern Web UI:** Responsive Drawer Navigation, Split-screen Dual Reader, Dynamic Continuous Stream Feed (Auto-scroll pagination)
- **Authentic Typography Engine:** ဆဋ္ဌမူ မူရင်းစာအုပ်ကြီးအတိုင်း ဂါထာပါဠိတော်များ၏ ပုဒ်ထီး ( ၊ )၊ ပုဒ်မ ( ။ ) နှင့် ပေယျာလ (`။ ပ ။`) အလိုအလျောက် သန့်စင်စနစ်
- **Instant Search & Stemming Dictionary:** မီလီစက္ကန့်ပိုင်းအတွင်း ရှာဖွေနိုင်သော Universal Search နှင့် ပါဠိ ဝိဘတ်ဖြုတ်နည်းစနစ်
- **Modern LocalStorage History Engine:** Chrome/Safari အဆင့်မီ ဖတ်ရှုမှုနှင့် ရှာဖွေမှု အလိုအလျောက် မှတ်တမ်းစနစ် (ရက်စွဲအလိုက် အုပ်စုဖွဲ့ခြင်း၊ Filter စစ်ထုတ်ခြင်းနှင့် ၁ ချက်နှိပ်ရုံဖြင့် မူလနေရာသို့ တိုက်ရိုက်ပြန်ရောက်ခြင်း)
- **Real-time TOC & Sticky Mobile Reading Tracker:** စာဖတ်နေစဉ် လက်ရှိရောက်ရှိနေသော မာတိကာ အခန်းခေါင်းစဉ်နှင့် စာမျက်နှာကို အချိန်နှင့်တပြေးညီ ခြေရာခံခြင်း၊ Desktop တွင် Sticky Current Chapter Card နှင့် Active Pulsing Highlight၊ Mobile တွင် အောက်စာမျက်နှာများသို့ scroll ဆင်းသော်လည်း မပျောက်ကွယ်ဘဲ အမြဲတမ်း ပေါ်နေသော Sticky Floating Breadcrumb Bar (နှိပ်လျှင် မာတိကာ drawer တိုက်ရိုက်ပွင့်သည့်စနစ်)
- **Zen / Focus Fullscreen Reading Mode (Tap-to-Toggle):** စာဖတ်နေစဉ် အာရုံစူးစိုက်ဖတ်ရှုနိုင်ရန် Header၊ Bottom Nav Bar နှင့် Browser ဘားများကို ဖျောက်ပေးသည့် စစ်မှန်သော မျက်နှာပြင်ပြည့်စနစ်၊ စာမျက်နှာကို တစ်ချက်ထိ (Tap) ရုံဖြင့် ဘားများ ပုန်း/ပေါ် ချောမွေ့စွာ ပြောင်းလဲနိုင်ခြင်းနှင့် Floating Mini Exit Button ပါဝင်မှု
- **Dynamic Companion Split-View Engine:** မူလပါဠိတော်၊ အဋ္ဌကထာ၊ ဋီကာ၊ မြန်မာပြန် ကျမ်းစာများကို ဘေးချင်းယှဉ်တွဲ၍ စာပိုဒ်နံပါတ်အလိုက် အလိုအလျောက် တိကျစွာ ချိန်ညှိပေးနိုင်သော Smart Paragraph & Multi-Volume Synchronization စနစ်၊ ညာဘက်ခြမ်း Dynamic Tabs စနစ်နှင့် အပြန်အလှန် အဘိဓာန် ထောက်ကူစနစ်
- **Progressive Responsive Toolbar:** မျက်နှာပြင် အကျယ်အဝန်းအလိုက် ခလုတ်များ အပြင်သို့ ကျွံမထွက်စေဘဲ ၄ ဆင့်ခွဲ၍ အချိုးကျ ပုန်းကွယ်ပေးသော စနစ်တကျ CSS Engine

အစရှိသော အဆင့်မြင့် နည်းပညာပိုင်းဆိုင်ရာများနှင့် ပြဿနာဖြေရှင်းမှုများကို **Google DeepMind ၏ Antigravity AI** အကူအညီဖြင့် အသေးစိတ် အဆင့်ဆင့် တိုင်ပင်ဆွေးနွေးကာ ရေးသားတည်ဆောက်ခဲ့ခြင်း ဖြစ်ပါသည်။ နည်းပညာ အခက်အခဲများကို လွယ်ကူလျင်မြန်စွာ ကျော်လွှားနိုင်စေခဲ့သော AI နည်းပညာအားလည်း အထူးပင် မှတ်တမ်းတင် ဂုဏ်ပြုအပ်ပါသည်။
