ပါဠိ-မြန်မာ အဘိဓာန်
📖

ပါဠိစကားလုံးကို ကလစ်နှိပ်ပါ

စာဖတ်နေစဉ် မသိသော ပါဠိစကားလုံး တစ်လုံးချင်းစီကို Click နှိပ်လိုက်ရုံဖြင့် တိပိဋက ပါဠိ-မြန်မာ အဘိဓာန် အဓိပ္ပာယ် ဤနေရာတွင် ချက်ချင်း ထွက်ပေါ်လာမည် ဖြစ်ပါသည်။

ပါဝင်သော အဘိဓာန်များ -
  • တိပိဋက ပါဠိ-မြန်မာ အဘိဓာန်
  • ဦးဟုတ်စိန် ပါဠိ-မြန်မာ အဘိဓာန်
  • ဓာတွတ္ထပန်းကုံး နှင့် ပါဠိဓာတ်အဘိဓာန်
  • PTS Pali-English Dictionary
  • Concise Pali-English Dictionary

💡 ပါဠိစာလုံး (ဥပမာ- ဗုဒ္ဓ၊ နိဗ္ဗာန၊ သတိပဋ္ဌာန) သို့မဟုတ် မြန်မာပြန်ခေါင်းစဉ်များ ရိုက်ထည့်၍ ရှာဖွေနိုင်ပါသည်။

ဖတ်ရှုမှုနှင့် ရှာဖွေမှု မှတ်တမ်းများ (History)
တိပိဋက Web App အသုံးပြုနည်း လမ်းညွှန်ချက် အပြည့်အစုံ

🙏 သာသနာတော်အကျိုးငှာ အဆင်ပြေစေရန် တည်ဆောက်ထားသော နည်းစနစ်များ

ဤ Web Application သည် ဆဋ္ဌသင်္ဂါယနာ တိပိဋက ပါဠိတော် (၁၉၂ အုပ်) နှင့် တိပိဋက မြန်မာပြန် (၆၀ အုပ်)၊ အဋ္ဌကထာ၊ ဋီကာ ကျမ်းစာများနှင့် ပါဠိ-မြန်မာ အဘိဓာန်များကို ရဟန်း၊ ရှင်၊ လူ၊ သာသနာ့နွယ်ဝင် ကျောင်းသား၊ ကျောင်းသူများ မည်သည့်စက်ပစ္စည်းမှမဆို အလွယ်ကူဆုံး၊ အလျင်မြန်ဆုံး လေ့လာဖတ်ရှုနိုင်ရန် ဖန်တီးထားခြင်း ဖြစ်ပါသည်။

၁ ဖတ်ရှုမှု ပုံစံ ၃ မျိုး (Reading Modes)

အပေါ်ဘားရှိ ခလုတ် ၃ ခုဖြင့် မိမိနှစ်သက်ရာ ဖတ်ရှုမှုစနစ်ကို လွတ်လပ်စွာ ပြောင်းလဲနိုင်ပါသည် -

☸️
ပါဠိတော် Mode

ဆဋ္ဌသင်္ဂါယနာ မူရင်းပါဠိတော် (မူလ၊ အဋ္ဌကထာ၊ ဋီကာ စုစုပေါင်း ၁၉၂ အုပ်၊ စာမျက်နှာ ၅၉,၀၀၈ မျက်နှာ) ကို စာအုပ်အစစ်ကဲ့သို့ သီးသန့်ဖတ်ရှုနိုင်ပါသည်။

🇲🇲
မြန်မာပြန် Mode

သာသနာရေးဦးစီးဌာနမှ ထုတ်ဝေသော တိပိဋက မြန်မာပြန် ကျမ်းစာအုပ် ၆၀ (ဇာတ်တော် ၅၅၀၊ ဓမ္မပဒ၊ ဝိသုဒ္ဓိမဂ် အပါအဝင် စာမျက်နှာ ၂၃,၃၉၀ မျက်နှာ) ကို သီးသန့်ဖတ်ရှုနိုင်ပါသည်။

📖
ယှဉ်တွဲဖတ်ရှုခြင်း (Dual Split View)

ဘယ်ဘက်တွင် ပါဠိတော် နှင့် ညာဘက်တွင် မြန်မာပြန် တို့ကို ဘေးချင်းယှဉ်တွဲ၍ တစ်ပြိုင်နက် ဖတ်ရှုနိုင်ပါသည်။ စာမျက်နှာမညီပါက ဘယ်/ညာ သီးခြားစာမျက်နှာ လှန်နိုင်သလို စာပိုဒ်နံပါတ်ကို နှိပ်၍လည်း တစ်ဖက်ရှိ စာပိုဒ်သို့ တိုက်ရိုက် ခုန်ကူး highlight ပြသပေးပါသည်။

၂ ပါဠိ နှင့် မြန်မာပြန် အပြန်အလှန် ခုန်ကူးဖတ်ရှုနည်း (Instant Cross-Link)

  • ပါဠိတော် ဖတ်ရှုနေစဉ်: အပေါ်ဘားရှိ 🇲🇲 မြန်မာပြန်သို့ ခလုတ်ကို နှိပ်လိုက်သည်နှင့် လက်ရှိဖတ်နေသော စာပိုဒ်နှင့် ကိုက်ညီသည့် မြန်မာပြန် စာမျက်နှာသို့ တိုက်ရိုက် ခုန်ကူးရောက်ရှိသွားပါမည်။
  • မြန်မာပြန် ဖတ်ရှုနေစဉ်: အပေါ်ဘားရှိ ☸️ ပါဠိတော်သို့ ခလုတ်ကို နှိပ်လိုက်ပါကလည်း မူရင်း ပါဠိတော် စာမျက်နှာသို့ တိုက်ရိုက် ပြန်လည်ရောက်ရှိပါမည်။
  • အဋ္ဌကထာ/ဋီကာ ကူးလိုလျှင်: အပေါ်ဘားရှိ တွဲဖက်ကျမ်း ခလုတ်ကို နှိပ်၍ သက်ဆိုင်ရာ အဋ္ဌကထာ သို့မဟုတ် ဋီကာသို့ ချက်ချင်း ကူးပြောင်းနိုင်ပါသည်။

၃ ကလစ်တစ်ချက်နှိပ်ရုံဖြင့် အဘိဓာန် အနက်ကြည့်ရှုနည်း (Instant Click-to-Lookup)

👆
စာလုံးကို Click နှိပ်ရုံမျှဖြင့် အနက်ထွက်ပေါ်ခြင်း:

ပါဠိစာဖတ်နေစဉ် မသိသော ပါဠိစကားလုံးကို Mouse ဖြင့် Click တစ်ချက် နှိပ်လိုက်ရုံဖြင့် ညာဘက်ခြမ်းရှိ အဘိဓာန်ပြားတွင် အဓိပ္ပာယ် ချက်ချင်း ထွက်ပေါ်လာမည် ဖြစ်ပါသည်။

🧠
ပါဠိ ဝိဘတ်ဖြုတ်နည်းစနစ် (Smart Pali Stemming):

ဥပမာ- ဗုဒ္ဓေါ ဟု ကလစ်နှိပ်သော်လည်း အဆုံးသတ်ဝိဘတ် -ော ကို စနစ်က အလိုအလျောက် ဖြုတ်ပေးပြီး မူရင်းပုဒ် ဗုဒ္ဓ ၏ အနက်ကို ရှာဖွေပြသပေးပါသည်။ ထို့အတူ ဓမ္မဿ၊ သမ္မာသမ္ဗုဒ္ဓဿ စသည်တို့ကိုလည်း မူရင်းပုဒ်အနက် ထွက်ပေါ်စေပါသည်။

📚
အဘိဓာန် ၈ မျိုးလုံးမှ တစ်ပြိုင်နက် ပြသခြင်း:

တိပိဋက ပါဠိ-မြန်မာ အဘိဓာန်၊ ဦးဟုတ်စိန် ပါဠိ-မြန်မာ အဘိဓာန်၊ ဓာတွတ္ထပန်းကုံး၊ ပါဠိဓာတ်အဘိဓာန်၊ PTS Pali-English စသည့် အဘိဓာန် ၈ မျိုးစလုံးမှ ဖွင့်ဆိုချက်များကို တစ်နေရာတည်းတွင် စုံလင်စွာ ဖတ်ရှုနိုင်ပါသည်။

၄ အလွန်လျင်မြန်သော ရှာဖွေမှုစနစ် (Universal Search - Ctrl + K)

Keyboard ပေါ်မှ Ctrl + K (သို့မဟုတ် / သို့မဟုတ် အပေါ်ဘားရှိ ရှာဖွေရန်ခလုတ်) ကို နှိပ်၍ အောက်ပါတို့ကို မီလီစက္ကန့်ပိုင်းအတွင်း ရှာဖွေနိုင်ပါသည် -

  • ပါဠိစကားလုံး (Word Index): စာလုံးပေါင်း ၉ သိန်းကျော် ကို ကြိုတင် Index ပြုလုပ်ထားသဖြင့် စာလုံးတစ်ခု ကျမ်းစာများအတွင်း မည်သည့်နေရာတွင် ဘယ်နှစ်ကြိမ်ပါဝင်သည်ကို မျက်စိတစ်မှိတ်အတွင်း ရှာတွေ့နိုင်ပါသည်။
  • သုတ္တန်များ (Suttas): သုတ္တန်ပေါင်း ၆,၈၈၁ ပုဒ် ကို အမည်ဖြင့် တိုက်ရိုက် ရှာဖွေနိုင်ပါသည်။
  • ကျမ်းစာအုပ်များ: ပါဠိကျမ်းစာ ၁၉၂ အုပ် နှင့် မြန်မာပြန်ကျမ်းစာ ၆၀ အုပ်ကို အမည်ဖြင့် အမြန်ရှာဖွေနိုင်ပါသည်။
  • မာတိကာများ: အခန်းကဏ္ဍပေါင်း ၁ သောင်းကျော် ကို ရှာဖွေနိုင်ပါသည်။

* တွေ့ရှိသည့် ရလဒ်ကို နှိပ်လိုက်သည်နှင့် သက်ဆိုင်ရာ စာမျက်နှာသို့ တိုက်ရိုက်ရောက်ရှိပြီး စာလုံးကို အရောင်တင် (Highlight) ပြသပေးပါသည်။

၅ စာဖတ်ရှုရ လွယ်ကူစေသော အခြား အထောက်အကူများ

🎨 မျက်စိအေးစေသော Themes ၃ မျိုး

📜 စက္ကူရောင် (Paper) - စာအုပ်အစစ်ဖတ်ရသကဲ့သို့ နွေးထွေးသော အဝါဖျော့ရောင်
☀️ နေ့ရောင် (Day) - ကြည်လင်ပြတ်သားသော အဖြူရောင်
🌙 ညရောင် (Night) - မျက်စိမညောင်းစေသော Dark Slate

🔤 စာလုံးအရွယ်အစား (Font Size)

အပေါ်ဘားရှိ A- နှင့် A+ ခလုတ်များဖြင့် စာလုံးအရွယ်အစားကို ၇၀% မှ ၂၀၀% ထိ မိမိမျက်စိနှင့် ကိုက်ညီအောင် လွတ်လပ်စွာ ချိန်ညှိနိုင်ပါသည်။

🔖 စာမျက်နှာ မှတ်သားခြင်း (Bookmark)

ဖတ်လက်စ စာမျက်နှာကို Bookmark မှတ်ထားနိုင်ပြီး နောက်တစ်ကြိမ် App ဖွင့်သည့်အခါ နောက်ဆုံးဖတ်ခဲ့သည့် နေရာမှ အလိုအလျောက် ပြန်လည် စတင်ပေးပါသည်။

🕒 ဖတ်ရှုမှုနှင့် ရှာဖွေမှု မှတ်တမ်း (History)

ဖတ်ရှုခဲ့သမျှ စာအုပ်များနှင့် ရှာဖွေမှုများကို ရက်စွဲအလိုက် စနစ်တကျ မှတ်တမ်းတင်ပေးထားပြီး Ctrl + H ဖြင့် အချိန်မရွေး ပြန်လည်ဖွင့်ကြည့်နိုင်ပါသည်။

မှတ်တမ်း၊ မှတ်စုနှင့် ဆက်တင်များကို JSON ဖိုင်ဖြင့် Backup သိမ်း/ပြန်တင်နိုင်ပြီး၊ အပတ်စဉ်ဖတ်ရှုမှုနှင့် အများဆုံးလေ့လာသော ပိဋကတ်စာရင်းအင်းများကို ကြည့်ရှုနိုင်ပါသည်။

✨ စာလုံးဆင့် သန့်စင်မှု နှင့် သတ်ပုံ

စာကြောင်းအဆုံး၌ စာလုံးဆင့်များ ပြတ်တောက်၍ + ပေါ်ခြင်းကို ကာကွယ်ထားပြီး ဆဋ္ဌမူ မူရင်းအတိုင်း ဂါထာပုဒ်ထီး (၊) ပုဒ်မ (။) များကို စနစ်တကျ ပြသပေးပါသည်။

၆ လက်ကွက်ဖြတ်လမ်းများ (Keyboard Shortcuts)

Shortcut ခလုတ် လုပ်ဆောင်ချက်
[ သို့မဟုတ် Arrow Left (◀) ယခင် စာမျက်နှာသို့ ကူးပြောင်းရန် (Previous Page)
] သို့မဟုတ် Arrow Right (▶) နောက် စာမျက်နှာသို့ ကူးပြောင်းရန် (Next Page)
Ctrl + K သို့မဟုတ် / ရှာဖွေရေး Modal ဖွင့်ရန် (Universal Search)
Ctrl + H သို့မဟုတ် H ဖတ်ရှုမှုနှင့် ရှာဖွေမှု မှတ်တမ်း ဖွင့်ရန် (History)
Esc Modal များ၊ အသုံးပြုနည်း၊ အဘိဓာန် Popup ပိတ်ရန်
